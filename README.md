# Internship Portal

## Project Overview

Internship Portal is a simple website created using HTML and CSS.
It provides information about internship programs, the team, and contact details.

## Technologies Used

- HTML5
- CSS3

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in a web browser.

## Git Workflow

This project follows a feature-branch workflow.

- main - Main branch containing the completed project.
- feature/home - Home section development.
- feature/about - About section development.
- feature/programs - Internship Programs development.
- feature/team - Team section development.
- feature/contact - Contact section development.

Changes are developed on feature branches and merged into the main branch after completion.

## Git Commands Learned

- git status - Check the current state of the repository.
- git add - Add changes to the staging area.
- git commit - Save changes in Git history.
- git log - View commit history.
- git branch - View or manage branches.
- git switch - Switch between branches.
- git merge - Combine changes from different branches.
- git diff - View differences between changes.

## Challenges Faced

One of the challenges was understanding the Git workflow and learning how branches, commits and merges work together.
